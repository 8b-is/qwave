Qwave / support

Let’s get you
back to browsing.

A few useful first steps, and a clear way to report what went wrong.

Install the beta

The current beta is invitation-only. Install Apple’s TestFlight app on your Mac or iPhone, then open your invitation and accept it using the invited Apple Account. Qwave should appear in TestFlight with an Install button.

No invitation? There is no public beta link yet. You can follow the Qwave repository for project updates.

Report a problem

For beta feedback, use Send Beta Feedback in TestFlight. For a public bug report, open a Qwave GitHub issue.

  • Include the Qwave version/build and macOS or iOS version.
  • Describe the steps you took, what you expected, and what happened.
  • If possible, include a screenshot with personal content removed.
GitHub issues are public. Do not include passwords, API keys, private browsing history, or sensitive page content.

If Qwave won’t open

Check for an update in TestFlight, then try opening Qwave again. Include any crash report in your beta feedback after reviewing it for personal information.

About this beta

Version 2.0.4 does not include the newer automatic translation controls or darker Wave panels. Those changes require a later build.
