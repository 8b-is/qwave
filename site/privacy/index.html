Qwave / privacy · updated October 14, 2026

Your data,
explained.

This notice describes Qwave’s macOS and iPhone/iPad features and this support site. Availability depends on your app version, platform and system capabilities. Different features send different information; local processing does not mean the whole browser is offline.

Browsing and search

Websites you open receive ordinary web requests, including your network address and information needed to display the page. Websites can use cookies and other storage under their own policies. Search terms go to your chosen search engine. Network autocomplete is optional and, when enabled, sends typed queries to the selected engine’s suggestion service.

Data on your device

Qwave keeps browser settings and browsing-related data in local app storage. Memory Wave records are encrypted on disk with a key held in Keychain. On macOS, Memory Wave can retain pages you explicitly pin. Its optional Remember everything setting captures additional browsing locally; private and ephemeral tabs are excluded from that capture path.

On iPhone and iPad, Remember this page saves the page title, address and a short hostname description. Saved-page suggestions reopen their original addresses. This path does not automatically capture every page or call a remote AI provider.

Optional AI processing

On macOS, the default Memory Wave provider is on-device processing, where supported by the system and hardware. If you choose an OpenAI-compatible remote provider and configure its credentials, explicitly asking or summarizing can send your question and included page text to that endpoint. A remote timeline summary sends saved titles, times and site hostnames, without saved page bodies. The provider’s own privacy and retention terms apply. Do not send sensitive pages to a provider you do not trust.

Passwords and AutoFill

The Mac app can save website passwords to OS Keychain and register service and account metadata with the system AutoFill index. The password stays in Keychain; password items are marked for iCloud Keychain synchronization when available through your Apple account. Qwave does not operate a password-sync service. The iPhone/iPad app does not include Qwave’s credential-provider extension. Website passkey availability depends on the platform and browser capabilities.

Page translation

Reading-language preferences and site/language exceptions are stored locally. On supported systems (macOS 15 or iOS 18 and later), Qwave uses Apple’s Translation framework to process page text on-device. Apple may ask to download language models. Qwave has no remote translation provider or cloud fallback; when translation is unavailable, the original page remains. Automatic translation can be disabled, and Show original restores the original text. Form values, password fields and editable content are excluded from translation.

Offline arcade

The two arcade games ship inside the app and run locally without network requests. Choosing Try again navigates back to the website you were trying to open, which resumes ordinary website network activity.

Diagnostics and beta feedback

Qwave’s macOS diagnostics component stores reports locally and has no Qwave telemetry upload endpoint. TestFlight and Apple’s crash-reporting features are separate services governed by Apple’s terms and your settings. Feedback you choose to submit can include screenshots, diagnostic information, and your comments.

App updates

App Store builds receive updates through Apple. Direct-download Mac builds can check the signed update feed on GitHub after you consent to automatic checks or request a manual check.

Support

When you send feedback, the information you provide is used to investigate and respond to the issue. Public GitHub issues are visible to others; avoid private content. You can manage your issue through GitHub or use the beta feedback channel.

This website

These static pages include no advertising scripts, analytics scripts, embedded trackers, forms, or third-party fonts. Links to external services are clearly visible. The hosting infrastructure may process request information such as IP addresses and requested URLs to deliver and secure the site.

Your choices

You can disable network suggestions on both platforms. On macOS, you can keep the remote AI provider disabled and turn off Remember everything. On iPhone and iPad, Clear saved Memory Waves removes saved Memory Wave records. Turning a feature off does not necessarily erase information already stored.

Qwave has no website-password deletion screen. Deleting a login outside Qwave does not guarantee that its system AutoFill suggestion metadata is removed. Memory Wave clearing does not delete website passwords. For data questions or removal requests, email c@8b.is. See our support page for other ways to get help.

Changes

This notice will be updated when the app’s data handling changes.
